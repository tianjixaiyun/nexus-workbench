# NEXUS · 个人工作台

深色科技感的个人效率工作台，提供任务管理（列表、看板、月历、日程）、习惯打卡、番茄钟、笔记便签、数据看板、快捷链接工具箱、全局命令面板、倒数日、天气和数据备份。默认本地存储；可通过设置向导配置自己的 Supabase 项目，建表并登录后使用云端同步。

## 任务时间与可迁移导出（2026-10-28）

- 任务可选截止时间（以当前设备本地时间计算），列表、日程和日历显示；按日期排序时，同一天有时间的任务按时间排列。重复任务保留时间；清除日期会同时清除时间。
- 工作台打开时显示最近 30 分钟内到期的未完成任务，关闭网页后不发送推送；回到页面时会重新检查。用户可关闭当前提示。
- 数据看板可导出未删除任务 CSV 或笔记 Markdown，并提供复制内容的备用入口；两个可读格式不替代完整 JSON 备份。CSV 内容保护表格公式，下载是否成功由浏览器决定。
- 日历 ICS 导出把带截止日期的未完成任务生成一次性日历标记（含标题和描述）：有时间时按当前设备时区换算，无时间则为全天。不会同步后续更改，也不自动生成重复或提醒；各日历软件的导入兼容性需在目标应用验证。使用 MIT 许可的 [ical-generator](https://github.com/sebbo2002/ical-generator)。
- 任务 CSV 支持导入预览：接受 NEXUS 导出表头或包含 title/标题的 CSV；每次最多 50 项、1 MB，标记可能重复的标题和日期，用户确认后追加；遇到未确认写入会停止并提示先核对。为表格软件安全而添加的公式前缀会作为文本保留。CSV 解析使用 MIT 许可的 [Papa Parse](https://github.com/mholt/PapaParse)。
- 本机模式可创建、编辑和删除个人任务模板；每行一项，模板可加入 JSON 备份的本机补充数据。模板仅保存在当前设备，云端模式暂不提供个人模板。批量生成任务逐条保存，遇到错误停止并提示核对未确认项。
- 周计划按周一到周日显示截止任务、具体时间与当天数量，支持切换周、按天新建、完成任务；沿用筛选并允许一键显示全部日期。未排期任务会给出数量提示。
- JSON 备份升级到 v13 以保留时间字段、本机个人模板和周视图偏好；仍可读取合法旧版备份，旧版应用不会错误地把新版备份当成完整旧备份。已有 Supabase 项目需要在“设置与同步”复制并运行任务时间更新 SQL，之后才能写入时间字段；无项目时可继续本机使用。未配置真实云端，不能声称跨设备实测通过。

## 助手与提示词升级（2026-10-28）

- **本地分析**：按已载入的数据计算概览、今日建议、截止提醒、习惯、专注和心情；检索可精确跳到任务或笔记。结果有日期和来源，未知问题明确说明能力范围，未加载时不把空数组当作零值结论。
- **提示词工坊**：今日规划、任务拆解、每周复盘、产品优化四个场景。编辑目标和约束后生成预览，可继续编辑、复制或发起Markdown下载。默认不带业务记录；显式开启后只附有限统计和任务元数据，不带笔记正文、任务描述、联系人与账目。
- **使用入口**：按A打开助手，或Ctrl/⌘+K搜索“提示词工坊”。原生dialog处理焦点、背景隔离、Esc和输入法；对话仅保留最近20轮，刷新或切换账号后清空。
- **能力边界**：没有自动调用外部LLM，不在浏览器保存模型私密密钥；提示词只是本机编排，由用户自行决定是否粘贴给外部AI。浏览器可能阻止下载，界面提供复制降级。

提示词结构依据[OpenAI官方指南](https://developers.openai.com/api/docs/guides/model-optimization)与[Anthropic官方指南](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices)；工作流参考[Todoist Assist](https://www.todoist.com/help/todoist/todoist-and-ai/introduction-to-todoist-assist-KgPP22q5O)与[Linear搜索](https://linear.app/docs/search)，未复制其界面或源码。

## 日程与快速捕捉升级（2026-10-27）

- **日程清单**：按具体截止日期与星期分组，显示今天、逾期及完成进度，支持按日新建、编辑和完成；兼容筛选、URL和保存视图。
- **批量添加**：快速捕捉选择“批量任务”，每行一条（最多50条），粘贴项目符号清单后预览标题、日期、优先级、重复与标签。也可从任务页和命令面板进入。
- **录入保护**：日期识别可关闭，单条描述与便签原文保留；保存防重入、输入法保护、错误留稿、关闭确认。批量非原子操作，遇错停止，只移除已确认保存的行，不自动重试；网络异常应先核对记录再重试。
- **日历细节**：同一天超过3条可展开全部，日期按钮支持键盘新建，手机“未排期”移到月历下方。
- **日期修复**：下周/下下周、有效ISO日期、无效日期原文保留、中文每月十五日、月末重复。

交互参考：[Super Productivity 按日计划（MIT）](https://github.com/super-productivity/super-productivity/blob/17c6227b39ad5a818a0aa2fc3803723dcf63213d/src/app/features/planner/planner-day/planner-day.component.html)、[Vikunja 快速录入（AGPL-3.0）](https://github.com/go-vikunja/vikunja/blob/1497ffb425cb3fa97f7916c3b707af6c8c86a084/frontend/src/components/tasks/AddTask.vue)。仅借鉴交互，未复制源码，未新增运行依赖或数据库表。

## 交互与云端连接升级（2026-10-27）

- **工作区导航**：按行动、记录、生活、展示分组；设置与同步、回收站固定可达，保留原快捷键。
- **任务工作流**：紧凑工具区与渐进筛选，保存命名视图以恢复条件和展示方式；实时刷新不覆盖正在编辑的任务草稿。
- **统一设置**：`/settings` 集中云端连接、外观、备份与数据检查。云端连接可在应用内配置，无需重新部署。
- **完整业务刷新**：11个业务模块纳入实时通知与手动刷新；切换账号清理旧订阅，旧请求不会回写新账号，离线与错误清楚可见。硬删除在返回页面或手动刷新后核对，不扩大订阅权限，也不后台轮询全部记录。

借鉴与许可证边界见[GitHub参考与实施取舍](docs/research/2026-10-27-cloud-experience.md)。使用现有React/Zustand/Dexie/Supabase架构，无新增运行时依赖；没有复制AFFiNE混合授权或Plane AGPL源码。

本轮按用户确认完成“暂无项目时的连接向导”，没有创建Supabase项目或执行真实SQL。云端配置、登录与刷新在契约及浏览器模拟服务下验证；真实登录、数据库隔离和跨设备通知需要创建项目后验收。

## 外网产品升级（2026-10-27）

- **任务行动视图**：全部、今日行动（含逾期）、未来 7 天（今天起共 7 个自然日）、未排期、已逾期、已完成，支持组合搜索标题/描述/标签、精确标签、状态、优先级和排序。列表、看板、日历共用筛选结果，网址保留筛选与展示方式；看板保持手动拖拽顺序。截止日期仍是截止日，没有新增独立计划日。
- **目标带出下一步**：自动标签目标可直接查看相关任务、添加继承标签的新任务；标签可继续修改，删除目标不会删除任务。
- **记录直达与专注衔接**：命令面板命中任务或便签后精确打开该记录，关闭保留其他筛选；无效或已删除链接有提示。任务可带着自身进入专注预选，不自动开始计时；已有运行或暂停的会话不会被新任务链接覆盖。
- **低干扰外观**：顶栏和命令面板可切换并在当前设备保存，减少拖尾、粒子、3D 与过场等装饰效果，同时尊重系统的减少动态效果偏好。
- **备份 v10**：选文件后先校验、预览数量与恢复范围，再确认写入；兼容合法旧备份，旧格式中缺失的集合默认保留当前数据。

**备份范围与恢复边界**：JSON 包含 11 个业务集合：任务、便签、链接、习惯、倒数日、每日复盘、目标、作品、碎碎念、记账、人脉；另可携带白名单本机补充数据，包括专注历史与实际分钟、手动编辑的工作日志、首页/外观/专注配置、个人档案、作品集介绍与 NOW 清单、本地留言及成就等。本机补充项默认不勾选恢复，需主动选择；活动计时、登录认证、PIN、缓存和未保存草稿不在备份范围内。

本地所选业务集合在 IndexedDB 事务内替换，云端模式按当前确认的账号追加并报告中断进度；本机补充数据在业务集合后独立恢复。这些步骤不构成跨存储的原子事务，失败时应按结果提示核对，避免直接重复导入已写入的业务数据。存在运行或暂停的专注会话时，需要先处理该会话再恢复备份。

沿用现有数据模型与组件，本轮没有新增数据库表或运行时依赖；`fake-indexeddb` 仅为开发测试依赖。真实 Supabase 项目未连接验证。

## 启用云端同步(可选)

推荐在应用内打开 **设置与同步 → 云端连接**（`/settings`）：

1. 打开[Supabase控制台](https://supabase.com/dashboard)，创建自己的项目，设置并妥善保存数据库密码。项目费用与额度以控制台为准。
2. 在NEXUS复制或下载建表SQL，到该项目SQL Editor执行。现有项目先保留备份；脚本包含11个业务集合的账号隔离规则、访问权限与实时发布配置。
3. 填入Project URL与 **Publishable key**，点击“检测连接”。浏览器拒绝Secret/service_role；检测只读Auth设置，不写业务数据。
4. 检测通过后保存并重新加载，在同一项目注册或登录。需要邮箱确认时按提示完成；登录后可在设置逐表检查读取能力并刷新数据。
5. 配置保存在当前浏览器，换设备填写同一项目并登录同一账号。业务数据云端存储；个人档案、专注历史、手写工作日志、外观及保存视图仍属于当前设备，部分内容可通过JSON备份迁移。

可选：若希望站点部署自带默认项目，复制`.env.example`为`.env`，配置并重新构建：

```dotenv
VITE_SUPABASE_URL=https://xxxxx.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

旧`VITE_SUPABASE_ANON_KEY`继续兼容合法anon JWT；不得填服务端密钥。浏览器显式选择的云端或本机配置优先于部署配置，保存失败不会切换模式。

本机与云端数据独立，切换不清空、不自动迁移。需要迁移时先导出JSON，在目标空间预览后选择恢复；云端导入为追加，异常后按提示核对，避免重复导入。活动专注需先重置再切换或恢复。

## 项目结构(后续加功能照这个套路)

```
supabase/schema.sql      云端建表脚本
.env.example             云端配置模板
src/
├── lib/
│   ├── config.ts        运行模式检测(本地/云端)
│   ├── utils.ts         通用工具函数
│   └── data/            数据访问层(核心扩展点)
│       ├── types.ts     实体类型:Task / Note / LinkItem
│       ├── adapter.ts   DataAdapter 统一接口
│       ├── localAdapter.ts   IndexedDB 实现
│       ├── cloudAdapter.ts   Supabase 实现
│       └── index.ts     自动选择实现
├── stores/              Zustand 状态(task/note/link/auth)
├── components/ui/       通用 UI 组件(Button/Card/Modal/Chart…)
├── layouts/AppLayout.tsx 侧边栏 + 顶栏布局
├── features/<模块>/     业务功能组件(页面主体逻辑)
└── pages/               路由页面(引用 features)
```

**加一个新功能模块的固定套路**:

1. `src/lib/data/types.ts` 加实体类型;`adapter.ts` 的 `DataAdapter` 接口加一个 `EntityStore`
2. `localAdapter.ts` / `cloudAdapter.ts` 各加实现(云端需同步在 `supabase/schema.sql` 加表)
3. `src/stores/` 加一个 store
4. `src/features/<新模块>/` 写组件,`src/pages/` 加页面,`App.tsx` 注册路由,`AppLayout.tsx` 加导航项

业务代码只依赖 adapter 接口和 store,不直接触碰 IndexedDB 或 Supabase —— 以后想换存储方案、加离线同步队列,只动 `lib/data/` 一层。
