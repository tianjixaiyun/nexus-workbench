## 实施选择

1. 任务行动闭环：全部、今日含逾期、未来七天、未排期、逾期、已完成，组合搜索、标签、状态和优先级；三种展示共用筛选结果，网址保留条件。截止日仍保持原含义，本轮不新增“计划日”字段。
2. 目标与记录直达：从自动目标查看相关任务、添加继承标签的下一步；搜索命中具体任务或便签即打开该记录；任务进入专注预选而不自动开始，已有活动会话受到保护。
3. 低干扰外观：顶栏与命令面板可切换，设备内持久保存；减少拖尾、粒子、3D、过场与计数动画，继续尊重系统减少动态效果。重要文字与统计直接显示。
4. 备份恢复：v10保留现有11个集合，并对白名单本机补充数据提供可选恢复；选文件后先校验、预览和确认。坏格式不得进入写库；旧格式缺失模块默认不选。本地选定集合事务恢复，云端追加固定账号并报告进度。本机补充恢复是独立分步操作，不宣称跨存储原子提交。

## 复用与许可证

优先复用本仓库165bb8b中已有的纯任务过滤器、移动修复和备份校验思路，按当前已发布模型适配。该旧提交的版本号和模板集合与当前模型不同，没有直接覆盖旧实现。外部产品仅提供交互参考，没有复制其源码、品牌资产、视频或付费界面；新增fake-indexeddb仅用于开发验证。

## 本轮不做

新的计划日/时间轴、自动抓取X、无条件视频转录、系统级应用屏蔽、付费LLM接入和完整项目对象数据库，需要独立的数据模型或服务授权；本轮不以占位界面冒充完成。

## 验收

针对任务日期、上下文、拖拽、动效偏好与备份写入边界先复现问题再修复；完成后统一执行 npm test 与 npm run build，并用独立浏览器验证桌面/手机、深浅主题、精确记录导航、低干扰切换及备份预览/取消/恢复。真实Supabase项目不在本轮测试中，云接口用契约测试覆盖。
